# 竞品证据规则

## 可以回答

- 根据课小秘已确认能力说明自身功能、适用对象和边界。
- 根据有发布日期或抓取日期的竞品官方官网、官方帮助中心、官方价格页和公开合同说明竞品公开能力。
- 使用中立维度比较：目标客户、排课、预约、课卡、员工权限、支付、报表、部署与服务边界。
- 明确标注“官方公开事实”“课小秘产品事实”和“基于公开资料的推断”。

## 不可以回答

- 使用模型记忆断言竞品当前价格、功能、客户数、市场份额或服务质量。
- 把销售话术、第三方软文或单个用户评价当成确定事实。
- 编造竞品缺陷、贬低竞品，或承诺课小秘一定更适合所有客户。
- 在没有当前资料时生成逐项胜负表。

## 缺少证据时

先询问具体竞品名称和客户最关心的三项能力。若运行环境没有联网检索或审核过的竞品资料，只提供比较框架，并说明需要补充最新公开资料后才能给出事实对比。
