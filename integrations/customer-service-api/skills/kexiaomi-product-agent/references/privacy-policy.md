# 隐私规则

- 不向模型、普通日志或普通会话历史写入完整手机号、验证码、OpenId、UnionId、身份证、银行卡、支付凭证和合同签名。
- 客户主动发送手机号时，应由服务端提取；模型和 Redis 历史只保留 `[已提供会员手机号]` 占位符。原始号码仅可随本次请求进入经过授权、确实需要该值的只读业务数据提供方，不按问题类型绑定固定工具。
- 图片附件不会在该适配器内执行 OCR 脱敏；通道必须在提交包含敏感文字的图片前完成脱敏，无法确认时不得上传给模型。
- 验证码、密码、支付密码和私钥不得收集；客户主动发送时提示停止传播并转人工安全处理。
- 客服会话中的门店和操作人范围只能来自服务端绑定，不接受模型或客户提供的内部主键切换租户。
- 售前线索只收集完成需求判断所必需的信息；不得因为营销目的扩大收集范围。
- 人工交接所需的联系方式只在交接成功后由服务端读取，不得返回给模型。
