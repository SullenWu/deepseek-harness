# 领域路由

先确定业务对象和用户希望完成的操作，再决定检索与调查路径。

| 领域 | 典型对象 | 典型操作或问题 |
|---|---|---|
| 身份与门店 | 平台用户、门店会员、员工关系、登录会话 | 登录、绑定、切店、账号归属 |
| 权限与版本 | 权限组、单项权限、软件版本、模块、服务期 | 按钮缺失、保存无权限、功能未开通 |
| 会员与课卡 | 门店会员、卡模板、持有卡、子卡、课程卡绑定 | 找卡、卡不可用、余额、有效期、合同 |
| 课程与排课 | 课程项目、课次、教练、场地、容量 | 创建课程、排课冲突、停课、人数限制 |
| 预约与候补 | 预约、候补、签到、取消、自定义字段 | 预约失败、候补转正、签到、退款回卡 |
| 员工与教练 | 正式员工、临时员工、教练、绑定会话 | 邀请绑定、离职、转交、排课资格 |
| 消费与支付 | 消费单、支付单、退款尝试、优惠券、积分 | 支付结果、重复扣款、退款部分成功 |
| 经营与售前 | 门店类型、规模、经营流程、报表、营销 | 产品介绍、方案匹配、价值说明、竞品比较 |

不要为“卡不可用”“绑定异常”等原话新增专用分支。相同原话可能对应不同实体和操作，必须结合当前端、页面、完整提示或 requestId 继续判断。
